Ejercicio 3 - sumatorio con condiciones

Escribe un programa que sume todos los números pares dentro de un rango dado por el usuario. Se solicitarán dos números enteros positivos (numero1 y numero2) al usuario y el programa deberá sumar todos los números pares del intervalo [numero1-numero2]. Si el usuario introduce el primer número mayor que el segundo deberán preguntarse ambos de nuevo.
