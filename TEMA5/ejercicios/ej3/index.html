Ej3

Crear un input de contraseña que muestre en tiempo real según el usuario escribe (Tendremos los mensajes ya escritos en elementos p y cambiaremos de rojo a verde según se cumpla o no la condición):

  • Si la contraseña tiene al menos 8 caracteres
  • Si la contraseña tiene al menos una mayúscula
  • Si contiene al menos un número

Usar el evento input para verificar mientras el usuario escribe. El script debe incluirse en el head de la página.
